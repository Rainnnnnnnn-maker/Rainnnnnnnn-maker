## About

名古屋を拠点に、クラウドネイティブなAPIとWebアプリケーションを開発しています。

- Azure / Cloudflare / Vercelを活用したサービス設計・開発・運用
- FastAPIによるAPI・マイクロサービス開発
- Next.js App RouterによるフルスタックWeb開発
- キャッシュ、パフォーマンス、信頼性、可観測性を意識した設計
- Azure DevOps / GitHub Actionsを利用したCI/CDとコンテナ運用

### [TOEIC語彙ラボ](https://www.toeic-words.com/)

[Source](https://github.com/Rainnnnnnnn-maker/toeic_website_ver2.0) · Next.js 16.2 / React 19 / TypeScript / Google Gemini / Upstash / Supabase / Vercel

TOEIC学習向けに、1,300語以上の英単語を例文・類義語・語形変化・音声とともに確認できるWebアプリケーションです。

- 目標スコア別の単語一覧、単語詳細、学習・復習モード

- ローカル保存に加え、任意のGoogleログインによるお気に入り同期
- PWA、動的OGP、構造化データ、学習ガイドなどのSEO対応
- Next.js Data CacheとUpstash Redisを組み合わせた多層キャッシュ
